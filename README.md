## Base de datos

**Antes de ejecutar el proyecto:**

1. Abrir SQL Server Management Studio (SSMS).
2. Ejecutar el script `Database/ClinicaBD_Completo.sql.txt`.
3. Verificar que se haya creado la base de datos `ClinicaBD`, sus tablas y procedimientos almacenados (SP).

**Importante:** Es necesario ejecutar el script previamente para que la aplicación pueda acceder a los procedimientos almacenados.
